## pstack

The `pstack` plugin in this repository is an independent portability-oriented
adaptation of Lauren Tan's `pstack`, originally published in the Cursor plugins
repository under the MIT License:

- https://github.com/cursor/plugins/tree/main/pstack
- https://x.com/poteto

The upstream project remains the source of the workflow concepts, names, and
engineering principles. This repository changes packaging and runtime-specific
instructions to target Claude Code and OpenAI Codex.
